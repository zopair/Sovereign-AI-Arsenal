# Factory Roadmap

## Phase 1 — Foundation

- Repository intake and capability detection
- Provider/component registry
- License-aware governance
- Deterministic stack planner
- GitHub Actions self-test and manual intake workflow

## Phase 2 — Intelligence Layer

- Repository adapters for GitHub, local clones, and archives
- Dependency and runtime inspection
- Component compatibility matrix
- Alternative recommendation engine
- Registry freshness and source verification

## Phase 3 — Build Orchestration

- Project templates for web, API, mobile, AI-agent, and full-stack applications
- Agent roles for architecture, implementation, testing, security, UI, and release
- Patch/branch/PR automation
- Reusable skills and project manifests

## Phase 4 — Quality Gates

- Unit/integration tests
- Browser/UI verification
- Android APK build/install/launch/navigation smoke tests
- API and database connectivity checks
- Security and secret scanning
- License compliance checks

## Phase 5 — Delivery

- Artifact generation
- Deployment adapters
- Release notes and changelog automation
- Rollback-aware releases
- Project status dashboard

## Phase 6 — Continuous Learning

- Record successful component combinations
- Record failed builds and fixes
- Promote verified fixes into reusable recipes
- Track component health, freshness, and compatibility
- Re-evaluate recommendations as upstream projects change

The factory must improve by accumulating verified engineering knowledge, not by silently changing project behavior.
